# PatchMaster - Patch Management Dashboard

A front-end dashboard UI for tracking software patches across a fleet of computers, built with HTML and CSS.

## What it shows
- Summary cards for patch and computer status
- A patch table with application, version, CVE, severity, CVSS score, status, size, and release date
- Search bar and an upload form for adding a new patch entry

## Tech
- HTML, CSS (no backend; this is a UI prototype, so actions such as Approve and Deploy are visual only)

## Run it
Open index.html in a browser, or serve the folder with any static file server.
